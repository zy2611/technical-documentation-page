Introduction

JavaScript is one of the most widely used programming languages today.

It is used for building interactive web pages and powerful web applications.

Developers rely on JS because of its flexibility and speed.

You can embed JavaScript directly into HTML documents.

Modern frameworks are built on top of JavaScript.

console.log("Hello World");
Syntax and Usage

JavaScript syntax is similar to many C-style languages.

Statements often end with a semicolon, although it's optional.

let x = 10; if (x > 5) { console.log("Hi"); }
  • Case-sensitive
  • Uses curly brackets
  • Supports comments
Variables and Types

JavaScript supports dynamic typing.

You can declare variables using let, const, or var.

let age = 20; const name = "Zy";
  • String
  • Number
  • Boolean
Functions

Functions are reusable blocks of code.

You can define a function using function keyword or arrow syntax.

function greet() { return "Hello"; } const add = (a, b) => a + b;
  • Named functions
  • Arrow functions
  • Anonymous functions
Arrays

Arrays store collections of data.

You can iterate through arrays using loops or array methods.

let nums = [1, 2, 3]; nums.forEach(n => console.log(n));
  • Push
  • Pop
  • Map
